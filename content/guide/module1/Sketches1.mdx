# Sketches 1

To create your sketch, as we've done before, click the "Create Sketch" tool. For our purposes, the plane you pick to create your sketch on does not matter right now, but going forward, it's best to select the top plane (or the x-z plane) unless otherwise specified.

![TourFiles](/assets/CreateSketch1.2.gif)
<small>Creating a sketch on the top, or x-z, plane.</small>

Here are some basic sketch tools that you'll be using the most to create 2D shapes. 

**Line Tool**: Select the start of your line, and specify the length and angle of the line. You can connect lines to create shapes with enclosed areas, which you can then extrude. 

![TourFiles](/assets/LineTool1.2.gif)
<small>Creating a line of 40mm with an angle of 40 degrees.</small>

> [!IMPORTANT]
>
> It is almost always better to input measurements when creating sketches instead of eyeballing. 

**Rectangle Tool**: The default way to create rectangles is the 2-point rectangle, which we've used before. Specify the first point, the height, and width. 

**Circle Tool**: By default, the circle tool requires you to specify the center point and the diameter.

**Polygon**: We can create a circumscribed polygon using the circle we've just created as a reference.

**Slot Tool**: Specify the centers of the two slot circles and the width of the slot.
